# 📊 Flipkart Smartphone Data Analysis – Power BI Project

This Power BI dashboard project provides an interactive, data-driven view of smartphone listings from **Flipkart**. Designed to offer business insights into pricing trends, customer sentiment, brand performance, and product segmentation — it's a modern take on e-commerce analytics for aspiring data analysts.

---

## 🧠 Project Objective

To explore and visualize how different smartphone brands and price segments perform on Flipkart in terms of:

- Customer Ratings & Reviews
- Pricing & Discounts
- Brand Popularity
- Sales Potential by Price Range

---

## 📌 Key Metrics Tracked

| KPI                        | Value (Sample)         |
|----------------------------|------------------------|
| ⭐ Average Rating           | 4.27                  |
| 🗣️ Average No. of Reviews | ~3,400                |
| 📊 Average No. of Ratings | ~47,000               |
| 💸 Average Discount        | ₹4,381                |
| 🔖 Brands Analyzed         | 29                    |
| 📈 Price Range Buckets     | Below ₹20K to ₹40K+   |

---

## 📊 Dashboard Views

| View                  | Description |
|-----------------------|-------------|
| **Brand Performance** | Compare ratings, reviews, and prices by brand |
| **Price Analysis**    | Explore discount strategies and pricing trends |
| **Customer Sentiment**| Ratings vs. number of reviews visualization |
| **Product Segmentation** | Filter by price range and identify top performers |
| **Interactive Filters**| Slicers for brand, price, rating & review count |
